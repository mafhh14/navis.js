# Navis.js v5.9 Features: Mobile, Face, and Bluetooth Authentication

## Overview

v5.9 adds device-based authentication for mobile apps:

- **Mobile verification** — signed device ID + timestamp
- **Face / biometric verification** — assertion tokens from Face ID, Touch ID, or fingerprint
- **Bluetooth verification** — BLE device proximity auth with challenge-response
- **Combined auth** — require multiple methods on one route

Lightweight and dependency-free. Works with Node.js HTTP servers and AWS Lambda.

## Mobile Device Authentication

Mobile apps sign requests with a shared secret after device registration.

### Headers

| Header | Description |
|--------|-------------|
| `x-device-id` | Unique device identifier |
| `x-device-timestamp` | Unix timestamp (ms) |
| `x-device-signature` | HMAC-SHA256 of `{deviceId}:{timestamp}` |

### Usage

```javascript
const {
  NavisApp,
  authenticateMobile,
  createMobileChallenge,
  sign,
} = require('navis.js');

const app = new NavisApp();
const secret = process.env.MOBILE_AUTH_SECRET;

// Issue challenge to mobile app
app.post('/auth/challenge', (req, res) => {
  res.body = createMobileChallenge(req.body.deviceId, { secret });
});

// Protected route
app.get('/api/data', authenticateMobile({ secret }), (req, res) => {
  res.body = { deviceId: req.mobile.deviceId };
});
```

## Face / Biometric Authentication

After Face ID or Touch ID on the device, the mobile app sends a signed biometric token.

### Headers

| Header | Description |
|--------|-------------|
| `x-biometric-token` or `x-face-token` | Signed assertion token |

### Usage

```javascript
const {
  authenticateFace,
  createBiometricToken,
} = require('navis.js');

// Mobile app obtains token after Face ID
const token = createBiometricToken(
  { userId: 'user-123', type: 'face', deviceId: 'device-001' },
  { secret: process.env.BIOMETRIC_AUTH_SECRET }
);

// Server middleware
app.get('/secure', authenticateFace({ secret }), (req, res) => {
  res.body = {
    userId: req.biometric.userId,
    type: req.biometric.type, // 'face'
  };
});
```

Supported types: `face`, `fingerprint`, `biometric`

## Bluetooth Authentication

Verify trusted BLE devices via challenge-response (proximity / paired device).

### Headers

| Header | Description |
|--------|-------------|
| `x-ble-device-id` | Bluetooth device MAC or ID |
| `x-ble-challenge` | Server-issued challenge |
| `x-ble-signature` | HMAC-SHA256 of `{deviceId}:{challenge}` |

### Usage

```javascript
const {
  authenticateBluetooth,
  createBluetoothChallenge,
} = require('navis.js');

app.post('/auth/ble/challenge', (req, res) => {
  res.body = createBluetoothChallenge(req.body.bleDeviceId, { secret });
});

app.get('/secure/ble', authenticateBluetooth({
  secret,
  registeredDevices: ['aa:bb:cc:dd:ee:ff'],
}), (req, res) => {
  res.body = { bleDeviceId: req.bluetooth.deviceId };
});
```

## Combined Device Authentication

Require mobile + face + bluetooth on a single route:

```javascript
const { authenticateDevice } = require('navis.js');

app.get('/vault', authenticateDevice({
  require: ['mobile', 'face', 'bluetooth'],
  secret: process.env.MOBILE_AUTH_SECRET,
  bluetooth: {
    registeredDevices: ['ble-beacon-001'],
  },
}), (req, res) => {
  res.body = { auth: req.deviceAuth };
});
```

## Environment Variables

| Variable | Purpose |
|----------|---------|
| `MOBILE_AUTH_SECRET` | Mobile device signing secret |
| `BIOMETRIC_AUTH_SECRET` | Face/biometric token secret (falls back to mobile secret) |
| `BLUETOOTH_AUTH_SECRET` | Bluetooth challenge secret (falls back to mobile secret) |

## Mobile App Integration Flow

1. App calls `POST /auth/challenge` with `deviceId`
2. App signs `{deviceId}:{timestamp}` with secret (stored in secure enclave)
3. User completes Face ID → app gets `createBiometricToken` from your auth endpoint
4. App scans BLE beacon → gets challenge from `POST /auth/bluetooth/challenge`
5. App calls protected route with all required headers
