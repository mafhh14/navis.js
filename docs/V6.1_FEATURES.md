# Navis.js v6.1 Features

## Overview

v6.1 polishes the v6.0 release with developer experience improvements:

- **Lambda response helpers** — `response.success()` and `response.error()` work with Navis Lambda `res` objects
- **gRPC proto loading** — Load `.proto` files into service definitions
- **Examples** — DynamoDB and gRPC demos
- **Test coverage** — Route middleware regression tests and Windows-safe test runner

## Lambda Response Helpers

Handlers can use `response.success(res, data)` on Lambda without `writeHead` errors:

```javascript
const { NavisApp, response } = require('navis.js');

const app = new NavisApp();

app.get('/hello', (req, res) => {
  response.success(res, { message: 'Hello Lambda' });
});

exports.handler = (event) => app.handleLambda(event);
```

The response helper auto-detects Navis Lambda `res` objects and sets `statusCode`, `headers`, and `body`.

## gRPC Proto Loading

```javascript
const path = require('path');
const {
  createGrpcServer,
  createGrpcClient,
  GrpcServer,
  loadProtoService,
} = require('navis.js');

const protoPath = path.join(__dirname, 'proto', 'hello.proto');
const HelloService = loadProtoService(protoPath, 'hello.HelloService');

const server = createGrpcServer({ port: 50051 });
server.addService(HelloService.service, {
  SayHello: GrpcServer.unaryHandler(async (call) => ({
    message: `Hello, ${call.request.name}!`,
  })),
});

await server.start();
```

Requires: `npm install @grpc/grpc-js @grpc/proto-loader`

### loadProto()

Load the full package tree from a `.proto` file:

```javascript
const { loadProto } = require('navis.js');

const pkg = loadProto('./proto/hello.proto', {
  includeDirs: ['./proto'],
});
```
