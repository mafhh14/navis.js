# Navis.js v6.2 Features

## Overview

v6.2 extends AlertManager with additional notification channels:

- **Slack** — Incoming webhook with formatted attachments
- **PagerDuty** — Events API v2 integration
- **SNS** — AWS SNS topic publishing (optional SDK)

## Slack

```javascript
const { createAlertManager, AlertManager } = require('navis.js');

const alerts = createAlertManager();
alerts.addChannel(AlertManager.slackChannel({
  webhookUrl: process.env.SLACK_WEBHOOK_URL,
  username: 'Navis Alerts',
}));
```

## PagerDuty

```javascript
alerts.addChannel(AlertManager.pagerDutyChannel({
  routingKey: process.env.PAGERDUTY_ROUTING_KEY,
}));
```

## SNS

```javascript
alerts.addChannel(AlertManager.snsChannel({
  topicArn: 'arn:aws:sns:us-east-1:123456789012:alerts',
  region: 'us-east-1',
}));
```

Requires: `npm install @aws-sdk/client-sns`
